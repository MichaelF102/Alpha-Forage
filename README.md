# ⚡ AlphaForge: Multi-Factor Equity Research & Portfolio Construction

AlphaForge is an institutional-grade quantitative investment and research platform. It provides an end-to-end workflow for factor-based equity research, constrained portfolio optimization, historical strategy backtesting, Fama-French style factor attribution, and comprehensive risk analytics.

Built for quant researchers and portfolio managers, AlphaForge leverages modern portfolio theory (MPT) and multi-factor models to construct optimal portfolios from a custom universe (e.g., the Nifty 50) while enforcing realistic institutional constraints.

---

## 🚀 Features

### 1. 🔬 Quant Factor Model & Universe Selection
- **Multi-Factor Signals**: Constructs Momentum (12-1 month), Low Volatility (annualized daily std), Value (inverse P/E ratio), and Quality (ROE) metrics.
- **Percentile Ranking**: Ranks the universe of stocks relative to each factor.
- **Composite Scoring**: Combines ranks to select the Top 15 highest-scoring stocks.

### 2. ⚖️ Expected Returns & Portfolio Optimization
- **Factor-Derived Expected Returns**: Combines the risk-free rate, market risk premium, and factor tilts rather than relying on noisy historical averages.
- **Constrained MVO**: Employs **Riskfolio-Lib** (with **SciPy SLSQP** fallback) to maximize the Sharpe Ratio subject to institutional constraints:
  - Fully invested ($\sum w_i = 100\%$).
  - Weight bounds ($1\% \le w_i \le 10\%$).
  - Sector exposure limit (maximum $30\%$ in any single sector).

### 3. 📈 Strategy Backtesting
- Compares the **Optimized Factor Portfolio** against an **Equal Weighted Portfolio** (comprising all universe assets) and the **Nifty 50 Index Benchmark**.
- Provides dynamic wealth index charting and metrics calculations over custom user-specified date ranges.

### 4. 🧩 Performance Attribution (Fama-French Style)
- Isolates active return drivers by constructing long-short factor-mimicking portfolios (Top 10 minus Bottom 10 stocks on each factor rank).
- Decomposes active returns into systematic factor exposures (**Momentum**, **Volatility**, **Value**, **Quality**), **Market**, and **Residual** components.

### 5. 🛡️ Institutional Risk Analytics
- **Tail Risk**: Computes Historical & Parametric Value at Risk (VaR) and Expected Shortfall (Conditional VaR) at a 95% confidence level.
- **Advanced Ratios**: Calculates Beta, Tracking Error, Information Ratio, Treynor Ratio, Omega Ratio, Calmar Ratio, and Downside Deviation.
- **Stress Testing**: Simulates portfolio performance under negative market conditions (Market Crash -30%, Interest Rate Shock -10%, and Recession Shock -20%).

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/portfolio-optimization.git
   cd portfolio-optimization
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Calculations Engine**:
   Before launching the dashboard, generate the historical dataset, optimization weights, backtesting, and attribution results:
   ```bash
   python main.py
   ```
   This will download the required Nifty 50 data, run the optimization, and populate the CSV reports inside the `reports/` directory.

4. **Run the Streamlit Dashboard**:
   ```bash
   streamlit run main.py
   ```
   *Note: `main.py` is configured to run the backend engine when executed as a standard python script and serve the Streamlit landing page when run via streamlit.*
